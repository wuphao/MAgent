# 阶段 02 行动：先让不同结构产生同一语义

## 02-A1 建立四种等价输入

在 tests/fixtures/schema_variants/ 制作旧 RWE 风格 JSON、CSV 长表、Excel 宽表、嵌套 JSON，并共享一份手工 expected.json。为同日多记录、不同主体同名、备注和混合缺失增加独立案例。

先明确文件、表、行、列、数组路径的定位格式；行号是否含表头、数组索引是否从零开始写入协议注释。不得以 DataFrame 重排行号冒充原始行号。

## 02-A2 实现解析与画像

新增 ingestion/{manifest,parsers,profiler,legacy_rwe}.py。从 JSON、CSV 开始，再补 Excel。依赖在 pyproject 中声明。

profile 采用有界样本和全量基础统计，区分样本推断与完整扫描事实。空表、坏编码、重复表头、损坏文件返回具体错误；不返回“成功但零记录”。

## 02-A3 实现声明式执行器

新增 mapping/{spec,operators,executor,validator}.py；configs/mappings/ 放四种人工映射。
顺序：select/explode → 数值日期解析 → unpivot → 显式 join → 单位和枚举转换。每个算子实现结果计数、源位置传播及失败返回。

转换单位仅允许已登记且量纲一致的规则；带比较符数值保留比较关系。score 的单位不能被通用物理量换算误处理。

## 02-A4 接入业务发布

将合法候选批次事务发布到阶段 01 仓储；生成部分完成的接入报告和快照。旧导出文件的来源范围只能追溯到导出快照；缺原数据库记录定位时明确该限制，不能补造。

本阶段优先适配导出，不重写所有 rwe_data_tools 导入脚本。如果需要原数据库定位，另补来源元数据字段，保留旧消费方兼容。
