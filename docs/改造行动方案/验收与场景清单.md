# 验收与场景清单

本文件是八阶段共用的行为验收规范。所有阈值为本项目工程验收约定，不是论文结果或对真实数据效果的预先承诺。

## 1. 夹具与独立期望

使用合成主体 S001、S002。虚构 XX-v1 量表定义四项、每项 0—3、总分 0—12，高分表示该虚构测量维度更高，缺项时不计算总分；不赋予临床含义。S001 两次测评条目分别为 [1,1,1,1] 和 [2,2,1,1]，期望总分 4、6、数值差 2。日期由夹具明确提供。

同一事实编制旧导出 JSON、CSV 长表、Excel 宽表、嵌套 JSON；源位置不同，但投影后的主体、概念、值、时间、版本应一致。不得要求 evidence_id 跨独立来源相同。

期望值手工登记在 expected.json，说明计算依据；不调用被测映射或计分函数生成期望。为映射选择开发集与保留结构集，后者包含未进入提示词的字段命名和布局。

## 3. 出口指标

确定性合成夹具要求全部通过：来源定位正确率、预期事实保留率均为 100%；非法计划执行数、跨项目读取数、无依据数值替换数均为 0。这里的 100% 只针对明确列出的夹具，不泛化到任意数据。

LLM 映射评估分别统计：字段到概念准确率、记录保留率、已发布映射准确率、待补率、错误自动发布率、调用成本。以所有候选和所有必需字段为分母分别报告，不能通过全部拒绝提高准确率。保留集不调提示词；重复运行记录波动。门禁要求已知高风险歧义夹具无错误自动发布；实际覆盖率不足登记为未完成目标。

协作至少比较：同一证据与同一工具的单 Agent、固定专业流水线、定向复核方案。保持模型版本、输入与预算上限可比，同时报告实际调用/token/耗时、冲突解决率、错误修正数和错误新增数。控制实验分别关闭映射复核、反证审查和重复抑制，观察行为差异。正确性判断依靠独立期望或复核标注，不能只由生成结果的同一模型自评。

性能先记录阶段 01 基线；后续记录解析、映射、各能力、调度与报告的耗时分布。并发收益必须排除模型限流和缓存差异。不预先承诺提升比例。
