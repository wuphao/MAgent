# 阶段 07 设计：文本、知识与影像接入

## 目标与依赖

复用阶段 01—06 的协议和任务接口增加真实数据类型，不为每个模态重新建一套编排系统。最小交付涵盖机器可读文本/PDF、知识文档和一个经验证的 DiaMond 能力适配器。OCR 与新模型训练为独立能力扩展。

## 文本观测

TextParser 保留页码、段落和字符区间；抽取 Agent 输出主体、事件、时间、否定、推测、经历者和来源片段。校验器验证片段存在及位置对应。

Observation 标记 extraction_method 和语义审查状态。来源片段存在不代表抽取含义正确；家属病史、否定和未来计划需要专门验收。

扫描 PDF 无 OCR 时返回 capability_unavailable，不将零文本视为“无异常”。文本抽取结论和结构化表值冲突时通过相同 Challenge 协议复核。

## 知识服务

文档 → 版本化片段 → 精确/混合检索 → 候选规则 → 适用性校验 → InstrumentSpec/规则版本。

先实现有来源定位的小型文档库与精确检索，再按数据规模增加向量召回、重排。test/ 下实验 RAG 代码需按接口、依赖、出处保留和测试逐项核查后复用，不能直接作为已验收知识服务。

KnowledgeAgent 接收具体问题和上下文，返回片段引用及规则候选；不从 agent_outputs 字符串直接推导患者风险。资料冲突保留多个候选，规则激活由注册服务决定。患者证据和通用参考知识使用不同 kind。

## 影像资产和前置验证

ImagingAsset 保存检查/序列身份、模态、示踪剂、采集日期、空间信息、预处理描述和文件指纹。仅路径存在不足以运行模型。

分为 Inspect → ValidateCompatibility → Preprocess → Predict 四种能力。序列选择依据模态及元数据和模型要求，不能默认切片数最多即正确。多候选无法判定时要求序列说明。实际要求以模型代码、配置及验证材料核查结果登记，不在本阶段猜测预处理。

DiamondAdapter 封装 tools/diamond_tool.py 与 H5 转换流程；禁止仅把加载数组重命名为 T1/FDG 就认定兼容。空间、输入维度、强度及配准要求必须按实际模型要求核验。无法证明兼容则不可执行。

## 版本与缓存

缓存键包括有序输入文件内容摘要、序列选择、模型权重 hash、工具版本、预处理版本及参数。大型目录使用不可变资产清单及每文件指纹；不能仅以路径或 mtime 证明内容相同。

GPU Worker 独立进程，返回 ToolArtifact、日志摘要和真实模型版本。模型概率保留类别映射和校准说明，不当作通用可信度。

tools/mri_tool.py、pet_tool.py 的固定输出能力只能放演示/测试注册表，正式计划排除。没有 GPU、权重、合格输入时可验收拒绝路径，真实推理验收必须另行完成。

## 完成定义

文本抽取可定位且正确区分否定/主体；知识可回到版本化出处；影像不兼容输入被阻止，合格真实输入成功产生可追溯产物。外部条件不足登记为未完成能力，不宣布全模态完成。
