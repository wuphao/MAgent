# 能力可用清单

| 能力 | 状态 | 说明 |
|---|---|---|
| JSON/CSV/XLSX 确定性适配 | 已验收 | 支持陌生布局通过 mapping 配置接入 |
| 语义映射候选 | 已验收 | FakeModelGateway，真实 LLM 未作为必需验收条件 |

| DiaMond 兼容性验证 | 已验收 | 不兼容拒绝、缓存键失效；真实推理未验证 |
| 租约、恢复、outbox、依赖闭包 | 已验收 | 本地 SQLite 单机工作进程范围 |
