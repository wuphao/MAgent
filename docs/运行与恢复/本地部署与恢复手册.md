# 本地部署与恢复手册

## 安装与初始化

1. 使用 Python 3.11。
2. 安装项目依赖：`pip install -e .`；当前开发环境也可用 `sys.path=['src']` 运行。
3. 初始化不需要单独迁移命令。`SQLiteStore`、`TaskStore`、`DependencyStore`、`OutboxStore`、`LeaseStore` 在首次使用时创建或补齐表结构。
4. 本地配置参考 `configs/deployment/local.example.json`，不要写入真实密钥。

## 运行

## 恢复

恢复器处理三类本地状态：

- 过期 running 租约：重新置为 ready，晚到结果因 fencing token 不匹配不能覆盖新结果。
- staging 产物：校验内容 hash 后移动到不可变对象路径；hash 不匹配则删除。
- outbox：保留 pending 事件，消费端用 event_id 去重。

Python 调用：

```python
from pathlib import Path
from multi_agent.orchestration.recovery import RecoveryManager
from multi_agent.storage.sqlite import SQLiteStore
from multi_agent.storage.tasks import TaskStore

result = RecoveryManager(
    TaskStore(Path('data/v2/tasks.sqlite3')),
    SQLiteStore(Path('data/v2/stage02.sqlite3')),
).recover()
print(result)
```

## 备份与回滚

- 备份 `data/v2/*.sqlite3` 和 `data/v2/assets`。
- 应用回滚只切 CLI/API 入口和能力配置，不覆盖新运行数据。
- 若旧应用不兼容新 schema，使用备份的独立实例运行旧版本，不能让旧代码写入新库。

## 运维排查

- 查 run：读取 `tasks_v2` 中的 run_id/task_id/state/attempts。
- 查预算：读取 `budget_ledger_v2`。
- 查恢复：运行 `RecoveryManager.recover()`。
- 禁用能力：将对应 `configs/capabilities/*.json` 的 `availability` 改为 `unavailable` 或在请求中使用 `allowed_capabilities`。
- 真实 DiaMond：必须先满足 `evaluation/stage-07/imaging-compatibility.md` 中的真实输入、权重、checkpoint hash 和运行环境要求。
