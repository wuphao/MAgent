# 经典文献与引用脉络结论

课题：基于多智能体协作的神经退行性疾病辅助诊疗系统

## 1. 先给结论：你现在文献里哪些最“经典”

如果按“能不能作为文章主干”来判断，现在这些文献可以分成四层。

### 第一层：疾病诊疗标准，最经典，必须作为医学主干

1. **Revised criteria for diagnosis and staging of Alzheimer's disease: Alzheimer's Association Workgroup**
   - 这是 AD 诊断与分期的基础标准类文献。
   - 它定义了 AD 从临床综合征诊断走向生物学诊断的脉络，尤其是 amyloid、tau、CSF、PET、血液标志物等。
   - 你的系统如果涉及 AD 辅助诊断、分期、标志物解释，必须顺着它写。

2. **Alzheimer's Association clinical practice guideline for Diagnostic Evaluation, Testing, Counseling, and Disclosure of Suspected AD/ADRD**
   - primary care 和 specialty care 两篇指南都很关键。
   - 它们不是算法论文，但决定了“辅助诊疗系统应该服务什么临床流程”。
   - 你的多智能体分工可以直接从这里拆：病史、知情人信息、认知功能、行为症状、日常功能、神经系统检查、实验室、结构影像、FDG-PET、CSF、amyloid PET、遗传咨询等。

3. **阿尔茨海默病源性轻度认知障碍诊疗中国专家共识**
   - 对中文论文或国内课题非常重要。
   - 它提供中国临床语境中的 MCI due to AD 诊疗流程、筛查、鉴别、随访和管理依据。

**结论：疾病主干不能从 ADAgent 或 CARE-AD 开始，而要从指南和标准开始。**

### 第二层：神经退行性疾病 AI 诊断主干，最适合承接疾病与算法

1. **AI-based differential diagnosis of dementia etiologies on multimodal data**
   - 这是你现有文献中非常关键的一篇。
   - 它把问题从“AD/CN/MCI 分类”推进到“多种痴呆病因鉴别、混合病理、多模态数据、临床医生辅助”。
   - 对你的课题来说，它说明神经退行性疾病辅助诊疗不应该只做单病种分类，而要处理 AD、LBD、FTD、VD、精神因素、系统性因素、混合病因等复杂情况。

2. **E2AD**
   - 更偏 AD 影像模型和可解释报告。
   - 可以作为“AD 多模态影像和解释生成”的代表，但不是多智能体诊疗主干。

**结论：如果要证明你的系统为什么需要多源异构数据和鉴别诊断，最应该重点看 AI-based differential diagnosis 这篇。**

### 第三层：多智能体方法主干，经典性高，但不是医学特异

1. **MetaGPT**
   - 经典点是 SOP、角色分工、结构化中间产物。
   - 你的系统可以借鉴它来解释：多智能体不是简单聊天，而是按照临床流程生成可交接、可审查的中间结果。

2. **ReConcile**
   - 经典点是多模型/多 Agent 先独立推理，再讨论，再共识。
   - 适合支撑“为什么需要多个智能体提供不同视角”，但医学场景不能只靠投票，要转成证据审查。

3. **ArgMed-Agents / MedCollab**
   - 这两篇比 MetaGPT、ReConcile 更贴近医学。
   - ArgMed-Agents 强调论证结构、支持/反驳、符号推理。
   - MedCollab 强调异质临床证据、因果链、IBIS 论证图、GP-led 共识。
   - 你的课题如果要写“可解释协作推理”，这两篇比普通多 Agent 框架更对口。

**结论：多智能体主干应从 MetaGPT/ReConcile 引入通用协作，再落到 ArgMed-Agents/MedCollab 的医学证据论证。**

### 第四层：与你题目最接近的交叉应用，最新但还不能算“经典”

1. **CARE-AD**
   - 最接近“AD + 多智能体 + 真实世界纵向病历文本”。
   - 它的主线是：AD 早期风险信号藏在 longitudinal clinical notes 中，单模型难以捕捉多维临床决策，于是模拟多学科会诊。
   - 适合支撑你的“纵向病历文本、多专科 Agent、风险评估”。

2. **ADAgent**
   - 最接近“AD + 多模态工具调度 + LLM Agent”。
   - 它的主线是：AD 诊断依赖 MRI/PET 等多模态，但现有深度学习模型多为单模态或固定任务，难以处理缺失模态和多任务，因此需要 LLM Agent 调度多个工具并协调结果。
   - 适合支撑你的“影像/模型工具编排、缺失模态路由、协作协调器”。

3. **PPA pathology-confirmed multi-agent system**
   - 虽然不是 AD，但非常适合写神经退行性疾病多智能体诊断。
   - 它有专科 Agent 并行分析、整合 Agent、专家委员会审查、反馈修订，和真实 MDT 更像。

4. **PD multi-agent conversational AI**
   - 适合放在临床支持对话系统方向。
   - 但它更多是问答、建议、RAG 和专家评分，不是严格诊断队列验证。

**结论：CARE-AD 和 ADAgent 是你题目最近的“核心近邻文献”，但它们是 2025 年新工作，适合做前沿，不适合作为唯一经典基础。**

## 2. 你的文章应采用的主干脉络

最稳的文章脉络应该是：

```text
AD/ADRD 诊疗指南与诊断标准
        ↓
神经退行性疾病诊断需要多源、多模态、纵向、可解释证据
        ↓
传统 AI/深度学习实现了单模态或多模态预测，但仍存在黑箱、固定输入、缺失模态、临床流程脱节
        ↓
LLM Agent 提供了工具调用、任务规划、知识检索和自然语言解释能力
        ↓
通用多智能体方法证明了角色分工、SOP、共识、辩论和通信拓扑的价值
        ↓
医学多智能体进一步强调证据链、论证图、因果链、临床复核和安全性
        ↓
ADAgent、CARE-AD、PPA/PD 等前沿工作开始把多智能体用于神经退行性疾病
        ↓
但现有工作仍偏单任务、单数据类型或原型展示，缺少面向多源异构数据的完整辅助诊疗闭环
        ↓
因此提出“基于多智能体协作的神经退行性疾病辅助诊疗系统”
```

## 3. 顺着关键文章 introduction 能看到什么引用脉络

### 3.1 ADAgent 的引用脉络

ADAgent 的 introduction 是这样铺的：

```text
AD 是进行性、不可逆神经退行性疾病
→ 早期诊断对治疗、照护规划和支持重要
→ 传统诊断包括认知测试、临床评估、MRI、PET
→ 早期 AD 与正常老化表现接近，单一方法难直接判断
→ 多模态数据异质性和医生主观评估增加诊断难度
→ 深度学习 AD 模型出现，但多数依赖单模态
→ 少数多模态模型只能处理固定任务和固定模态
→ 需要能处理多任务、多模态/缺失模态，并协调多个模型的方法
→ LLM Agent 具备推理、规划和工具调用能力
→ 提出 ADAgent
```

所以顺着 ADAgent 往前追，应重点补三类文献：

- AD 早期诊断和 MRI/PET/认知量表相关基础文献。
- AD 单模态与多模态深度学习模型文献。
- LLM Agent 工具调用与医学 Agent 文献。

### 3.2 CARE-AD 的引用脉络

CARE-AD 的 introduction 是这样铺的：

```text
AD 早期信号常出现在长期病历叙述中
→ 这些信号常没有进入 ICD、实验室等结构化字段
→ 结构化 EHR 预测已有研究，但较少充分利用非结构化纵向 clinical notes
→ 传统 NLP 多关注孤立症状或特定 note 类型，泛化有限
→ GPT-4、LLaMA 等 LLM 带来自由文本理解机会
→ 医疗应用仍有隐私、可扩展性、单模型推理不足等挑战
→ AD 临床诊断依赖多学科协作
→ 用多智能体模拟神经科、精神科、老年科、初级保健、心理等专科
→ 提出 CARE-AD
```

所以顺着 CARE-AD 往前追，应重点补三类文献：

- 结构化 EHR 预测 AD 风险的文献。
- 非结构化 clinical notes / NLP 抽取 AD 早期症状的文献。
- MDT、多专科协作、MoE、多智能体医疗问答和认知偏差缓解文献。

### 3.3 MedCollab 的引用脉络

MedCollab 的 introduction 是这样铺的：

```text
临床诊断需要整合主诉、纵向病史、检查结果等异质证据
→ LLM 在医学问答和报告生成中表现强，但真实临床流程中有幻觉和解释不足
→ 多智能体框架通过专科分工改善单模型问题
→ 但现有多智能体诊断常把诊断视为独立关联输出
→ 只说症状和疾病相关，不解释病理因果进展
→ Agent 断言缺少可追踪、病例特异的逻辑审计
→ 引入 IBIS 论证协议和疾病因果链
→ 提出 MedCollab
```

所以顺着 MedCollab 往前追，应重点补：

- LLM 医疗幻觉与临床安全文献。
- 多智能体医学诊断框架。
- 临床论证、IBIS、argumentation scheme。
- 因果链、鉴别诊断、病理进展建模。

### 3.4 MetaGPT / ReConcile 的引用脉络

MetaGPT 的脉络：

```text
复杂任务需要多人协作
→ 人类协作依赖 SOP
→ 普通多 Agent 容易闲聊、职责混乱、交接不规范
→ 结构化中间产物能减少歧义和错误
→ 提出基于 SOP 的多 Agent 框架
```

ReConcile 的脉络：

```text
单个 LLM 推理会受自我偏差和过度自信影响
→ self-reflection 容易思想退化
→ 多 Agent debate 能增加思路多样性
→ 但同一模型多个实例仍有相同偏差
→ 不同模型组成的 Agent 通过讨论和说服形成更好共识
```

这两篇给你的不是医学结论，而是协作机制的理论支撑。

## 4. 你后续最应该补哪些“经典引用”

你现在的近邻文献已经够新，但“经典底座”还可以再补。建议按优先级补：

1. **AD/ADRD 诊疗标准**
   - NIA-AA 2011 AD/MCI 诊断标准。
   - NIA-AA 2018 research framework。
   - 2024 Alzheimer's Association revised criteria。
   - 2024/2025 DETeCD-ADRD primary care 与 specialty care guidelines。

2. **多模态痴呆诊断**
   - MRI/PET/CSF/血液标志物在 AD 诊断中的综述或指南。
   - ADNI 多模态 AD 预测/分类经典模型。
   - AI-based differential diagnosis of dementia etiologies 这篇的上游引用。

3. **LLM Agent 基础**
   - ReAct：推理与行动。
   - Reflexion / Self-Refine：反馈和自我修正。
   - AutoGen / ChatDev / MetaGPT：多智能体协作框架。
   - Multi-agent debate / ReConcile：辩论和共识。

4. **医学 LLM 与医疗 Agent**
   - 医学问答、临床推理、RAG、幻觉控制、证据引用。
   - ArgMed-Agents、MedCollab、MedAgent-Pro、ColaCare。

5. **神经退行性疾病 Agent 应用**
   - ADAgent。
   - CARE-AD。
   - AgenticAD。
   - PPA pathology-confirmed multi-agent system。
   - PD multi-agent conversational AI。

## 5. 最后判断：哪几篇应作为你综述的“核心文章”

如果只挑 8 篇作为主干，我建议这样排：

1. **Revised criteria for diagnosis and staging of Alzheimer's disease**
   - 疾病定义和分期主干。

2. **Alzheimer's Association DETeCD-ADRD guidelines**
   - 临床诊疗流程主干。

3. **AI-based differential diagnosis of dementia etiologies on multimodal data**
   - 多模态、病因鉴别、临床辅助主干。

4. **MetaGPT**
   - 多智能体 SOP 与结构化协作主干。

5. **ReConcile**
   - 多 Agent 共识与多样性主干。

6. **ArgMed-Agents 或 MedCollab**
   - 医学可解释协作推理主干；如果只能选一个，选 MedCollab，因为它更贴近完整临床诊断流程。

7. **MedAgent-Pro**
   - 医学多模态 Agent 工作流主干，强调指南、工具、证据检查。

8. **CARE-AD + ADAgent**
   - 这是你题目最近的两个前沿近邻：CARE-AD 对应纵向文本和多专科会诊，ADAgent 对应 AD 多模态工具调度和缺失模态。

如果论文篇幅有限，CARE-AD 和 ADAgent 可以合并写在“AD 多智能体辅助诊疗前沿探索”一节里。

## 6. 你的最终研究空白可以这样定

现有研究已经分别证明了：

- AD/ADRD 诊断需要标准化流程和生物标志物支持。
- 痴呆病因鉴别需要多源、多模态数据。
- LLM Agent 可以进行工具调用、规划和解释。
- 多智能体可以通过角色分工、讨论、共识和论证增强复杂推理。
- CARE-AD、ADAgent 等工作已经开始把多智能体用于 AD 预测或分析。

但仍然存在一个空白：

> 现有神经退行性疾病相关 Agent 工作多聚焦于单一任务，如 AD 风险预测、MRI/PET 诊断协调、照护问答或特定疾病分型；多数系统尚未围绕真实诊疗流程建立统一的多源异构数据解析、专业 Agent 分析、证据级协作复核、冲突处理、鉴别诊断和综合报告生成闭环。因此，有必要构建一个面向神经退行性疾病辅助诊疗的多智能体协作系统，使其能够在多模态、缺失数据和诊断不确定性场景下提供可追溯、可解释、可扩展的临床决策支持。
