# 文献综述文件夹文章四点总结

> 总结颗粒度：每篇围绕“解决了什么问题、使用什么方法和架构、效果怎么样、创新点与特别关注点”四个问题展开；其中“方法和架构”保留一段稍完整的机制描述，便于后续写文献综述时抽取。

## 一、AD-MAGENT：多智能体与神经退行性疾病的交叉工作

### 1. E2AD: Enhanced and explainable Alzheimer's disease detection framework via anatomy- and relation-aware cross-modal knowledge distillation

**解决的问题：** 临床上患者常缺少 PET，而仅用 MRI 又难以充分利用多模态信息，因此 E2AD 希望在实际使用时只输入 MRI，也能获得更好的 AD 判断，并生成便于医生理解的报告。

**方法与架构：** 先用 MRI+FDG-PET 训练教师模型，再通过分类结果、脑区关注权重和患者间特征关系三种知识蒸馏训练只用 MRI 的学生模型；核心模块包括 ROI 解剖分区 tokenizer、A-MoM 脑区特异/共享特征建模、DA-Router 差分注意力脑区加权，以及由信息整理、医学知识、相似病例检索和报告生成四个 DeepSeek-R1 智能体构成的报告生成流程。

**效果：** AD 分类在内部 ADNI 和外部 AIBL 上准确率分别为 90.3% 和 91.0%，MCI 进展预测在 ADNI 和 NACC 上分别为 73.9% 和 68.0%，比最强对照约提升 1-2 个百分点；报告质量在 20 例专家评价中优于 AutoRG-Brain。

**创新与关注点：** 核心创新是同时蒸馏“患者内部哪些脑区重要”和“患者之间如何相似”，并把模型的脑区权重接入报告生成；需要注意，脑区权重不等于真实萎缩程度，多智能体主要负责解释报告，分类性能提升不能直接归因于智能体协作。

### 2. CARE-AD: A multi-agent large language model framework for Alzheimer's disease prediction using longitudinal clinical notes

**解决的问题：** 这篇文章解决的是如何从长期、零散、非结构化的临床病程记录中提前识别 AD 风险，而不是依赖单次量表或影像检查。

**方法与架构：** 系统先用文本抽取模型从纵向临床 notes 中整理症状、时间线和风险信息，再由多个专科智能体分析不同临床维度，最后由 AD specialist agent 汇总多智能体意见并给出风险判断；整体更像“纵向病历文本理解 + 多专科会诊式汇总”，而不是影像模型。

**效果：** 研究使用 VHA 大规模真实世界临床记录，能在 AD 首次 ICD 诊断前多年给出风险信号，但 10 年前预测的准确率和阳性预测值仍有限，说明它更适合作为早筛提示而不是确诊工具。

**创新与关注点：** 价值在于把“时间顺序的临床叙事”纳入 AD 预测，并用多智能体模拟专科解释；但队列以男性退伍军人为主，且标签依赖 ICD 诊断时间，不能等同于真实疾病起病时间。

### 3. ADAgent: LLM Agent for Alzheimer's Disease Analysis with Collaborative Coordinator

**解决的问题：** 这篇文章尝试解决 AD 诊断/预后中 MRI、PET、量表等多模态数据如何由不同模型协同分析的问题。

**方法与架构：** ADAgent 采用 coordinator 协调器调度多个医学分析工具或模型，每个 agent 负责特定模态或任务，输出观察、思考、动作与概率判断，最后由协作协调器整合形成诊断或预后结论；它强调的是 LLM 作为“工具编排器”和“协作管理器”。

**效果：** 在 ADNI 相关诊断和 MCI 进展预测任务上，相比单模型或简单融合有小幅提升，例如多模态诊断和预后任务准确率有若干百分点改善，但整体提升幅度不算大。

**创新与关注点：** 它是较直接面向 AD 多模态分析的 agent 框架，适合放在你综述的交叉重点部分；但要注意其“协作”主要是模型/工具调度，不是深层辩论、冲突消解或因果推理。

### 4. Collaborative multi-agent conversational artificial intelligence for clinical support in Parkinson disease

**解决的问题：** 这篇文章解决的是帕金森病患者和临床场景中问答、诊断建议、治疗建议需要更准确、更有上下文、更少幻觉的问题。

**方法与架构：** 系统由 generation agents、critique agents 和 synthesis agent 组成，生成智能体基于 Qwen3-Medical-GRPO 和 PD 专属知识库生成候选回答，批判智能体从事实正确性、临床相关性和表达清晰度评估候选结果，综合智能体再整合成面向用户的回答；整体是“生成-审查-综合”的多智能体 RAG 对话架构。

**效果：** 文章报告诊断建议专家评分 4.8/5、治疗建议 4.6/5，并声称系统整体准确率约 95.5%，相比通用 ChatGPT/Gemini 回答更简洁、医学相关性更强。

**创新与关注点：** 它的亮点是把多智能体审查流程落到具体神经退行性疾病管理场景；但评估主要是问答质量和专家打分，不是严格的患者队列诊断验证，因此更适合作为“临床支持对话系统”而非诊断模型证据。

### 5. AgenticAD: A Specialized Multi-Agent System Framework for Holistic Alzheimer's Disease Management

**解决的问题：** 这篇文章试图解决 AD 管理不是单一诊断任务，而是同时涉及照护问答、医学知识检索、网页信息抽取、数据分析、影像理解和报告生成等多个环节的问题。

**方法与架构：** 作者提出一个由八类专业智能体组成的 AD 管理生态，包括照护/家庭支持 agent、RAG 文献问答 agent、网页抽取 agent、表格数据分析 agent、研究报告 agent、照护研究 agent、多模态 agent 和影像辅助 agent；不同 agent 通过共享上下文、显式 handoff、工具调用和结构化输出串联。

**效果：** 文章主要展示各 agent 的运行样例，例如照护计划生成、网页抽取失败后的 fallback、研究报告生成、图像分析和数据查询等，没有提供大规模临床诊断准确率或前瞻性患者验证。

**创新与关注点：** 它对你的课题有启发的是“完整 AD 辅助诊疗系统的功能分解”，但证据强度更接近系统蓝图和原型展示，不能当成已经验证有效的临床诊疗系统。

### 6. Agentic Generative Artificial Intelligence System for Classification of Pathology-Confirmed Primary Progressive Aphasia Variants

**解决的问题：** 这篇文章解决 PPA 分型和病理预测高度依赖多学科专家、基层难以获得同等诊断能力的问题。

**方法与架构：** 系统模拟 UCSF 多学科 clinico-pathological workflow，先由行为神经科、神经心理和神经影像三个专业 agent 并行分析临床资料、认知测试和 MRI，再由 integrator agent 形成综合诊断，随后由 expert board agent 按诊断标准和鉴别数据库审查，必要时 refinement agent 根据反馈重新分析。

**效果：** 在 54 例尸检确认且表现典型的 PPA 病例中，开放诊断场景识别 PPA 准确率为 90.7%；限定 PPA 后，svPPA 和 nfvPPA 分型准确率为 100%，lvPPA 为 94.1%，大类病理预测也达到较高准确率。

**创新与关注点：** 这篇是神经退行性疾病多智能体诊断中很值得重点写的工作，因为它有并行专科评估、专家委员会审查和反馈修订；但样本是典型病例且只有 54 例，不能说明其在复杂、不完整、非典型真实门诊中的表现。

## 二、AGENT 技术：多智能体协作方法

### 7. VOYAGER: An Open-Ended Embodied Agent with Large Language Models

**解决的问题：** VOYAGER 解决的是开放世界环境中智能体如何持续探索、积累技能并自我改进的问题。

**方法与架构：** 系统由自动课程学习、技能库和迭代提示机制组成：agent 在 Minecraft 中自主生成新目标，执行代码化技能，遇到错误后根据环境反馈和自我验证修改策略，并把成功技能保存到可检索的技能库中。

**效果：** 相比 ReAct、AutoGPT 等基线，VOYAGER 在探索里程、获得物品、解锁科技树和长期泛化任务上表现更好。

**创新与关注点：** 它不是典型多 agent 系统，但对你的课题有启发的是“可积累的工具/技能记忆”和“环境反馈驱动的闭环修正”，适合用于设计诊疗系统的可复用检查流程和错误纠正机制。

### 8. TradingAgents: Multi-Agents LLM Financial Trading Framework

**解决的问题：** 这篇文章解决金融决策中单一 LLM 很难同时处理新闻、基本面、技术面、情绪和风险偏好的问题。

**方法与架构：** TradingAgents 模拟交易公司结构，设置分析师、研究员、交易员、风险管理者和基金经理等角色，通过共享全局状态、bull/bear 辩论、交易决策、风险偏好复核和最终管理者决策形成多轮协作。

**效果：** 作者在 2024 Q1 的股票回测中报告比若干基线有更好的收益和风险指标，但测试时间窗口和股票范围有限，且没有充分分离“多智能体辩论”本身带来的贡献。

**创新与关注点：** 它适合作为“角色分工 + 反方辩论 + 风险复核”的通用协作模板，但金融回测证据不能直接迁移到临床诊断，需要重新设计医学证据门槛和安全边界。

### 9. ReConcile: Round-Table Conference Improves Reasoning via Consensus among Diverse LLMs

**解决的问题：** ReConcile 解决单个 LLM 推理不稳定、容易受自身偏差影响的问题，希望通过多个模型讨论达成更可靠答案。

**方法与架构：** 多个不同 LLM 先独立生成解释和置信度，再进行 round-table 式多轮讨论，之后通过置信度、历史表现或加权投票形成共识答案；关键机制是模型多样性和共识聚合。

**效果：** 在多类推理任务上通常优于单模型和简单投票，说明“先独立判断、再交换理由、最后共识”比直接让一个模型回答更稳。

**创新与关注点：** 对你的系统最有价值的是“异质智能体 + 共识形成”的协作思想；但临床任务中置信度不能天然视为校准概率，必须结合证据来源和医学规则审查。

### 10. MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework

**解决的问题：** MetaGPT 解决多个 LLM agent 协同写软件时容易职责混乱、信息交接不规范的问题。

**方法与架构：** 它把软件公司 SOP 编码到多智能体流程中，设置产品经理、架构师、工程师、测试等角色，并用结构化文档和消息作为中间产物，使每个 agent 按固定职责消费上游输出、生成下游输入。

**效果：** 在软件生成基准上比普通单 agent 或无结构协作更能产出完整项目和可执行代码。

**创新与关注点：** 它的核心价值不是某个医学模型，而是“标准作业流程 + 结构化中间产物”，非常适合借鉴到诊疗系统中的病史整理、检查选择、诊断推理、报告生成和复核流程。

### 11. MedCollab: Causal-Driven Multi-Agent Collaboration for Full-Cycle Clinical Diagnosis via IBIS-Structured Argumentation

**解决的问题：** MedCollab 解决多智能体医学诊断中证据零散、讨论不可追踪、结论缺少结构化论证的问题。

**方法与架构：** 系统用 IBIS 结构把诊断问题拆成 issue、position、argument、evidence，并设置动态专科 agent、检查 agent、审计/共识模块等角色，在诊断全流程中记录证据链、因果链和逻辑关系，再通过加权共识输出诊断。

**效果：** 作者在 ClinicalBench 和 MIMIC 派生病例上报告较高诊断性能，并展示了比普通 LLM 会诊更可解释的论证结构。

**创新与关注点：** 它最值得你重点吸收的是“把智能体讨论转成可审计论证图”；但文中的“causal”主要是临床因果链表达，并不等同于严格因果推断或因果效应识别。

### 12. MedAgent-Pro: Towards Evidence-based Multi-modal Medical Diagnosis via Reasoning Agentic Workflow

**解决的问题：** MedAgent-Pro 解决多模态医学诊断中模型容易跳步、缺少检查计划、证据质量难以控制的问题。

**方法与架构：** 它先根据疾病指南生成结构化诊断计划，再把患者数据转成可执行检查项，调用量化工具和视觉模型获取证据，并用可靠性检查判断证据是否 complete、continue 或 terminate，最后基于证据权重输出风险判断。

**效果：** 在青光眼和心脏疾病任务上，逐步加入计划、量化工具和证据检查后，平衡准确率从较低基线明显提升到约 90.4% 和 77.8%。

**创新与关注点：** 这篇非常适合解释“如何协作”：它不是让 agent 随便聊天，而是用指南驱动计划、工具调用、证据校验和终止条件组织诊断；注意其验证疾病不是 AD，需要迁移到神经退行性疾病时重新定义检查工具和证据标准。

### 13. GPTSwarm: Language Agents as Optimizable Graphs

**解决的问题：** GPTSwarm 解决多智能体系统拓扑通常靠人工设计、难以针对任务自动优化的问题。

**方法与架构：** 它把多个语言 agent 看成图中的节点，把消息传递看成边，通过可微或搜索式优化选择 agent 连接关系、通信路径和聚合方式，从而让多智能体协作结构随任务数据调整。

**效果：** 在多个问答和推理任务中，优化后的 agent 图通常优于手工固定拓扑和简单 ensemble。

**创新与关注点：** 对你的系统的启发是“诊疗 agent 不一定只能线性流水线，也可以学习或搜索协作图”；但医学场景需要可解释和可控，不能只追求图结构性能最优。

### 14. G-Designer: Architecting Multi-agent Communication Topologies via Graph Neural Networks

**解决的问题：** G-Designer 解决的是不同任务需要不同通信拓扑，而人工指定全连接、链式或星形结构可能低效且不稳定的问题。

**方法与架构：** 文章用图神经网络或变分图建模方法，根据任务状态生成 agent 之间的通信拓扑，使哪些 agent 通信、通信强度如何、是否稀疏化都可以被学习。

**效果：** 在多智能体推理基准上，任务条件化的通信图相比固定拓扑有更好的性能和效率。

**创新与关注点：** 这篇适合写进“协作拓扑优化”小节；落到诊疗系统时，它提示我们可以按患者数据缺失情况动态决定让影像、量表、基因、指南和报告 agent 如何连接。

### 15. ColaCare: Enhancing Electronic Health Record Modeling through Large Language Model-Driven Multi-Agent Collaboration

**解决的问题：** ColaCare 解决 EHR 预测模型可解释性不足、专家知识难以和深度模型特征融合的问题。

**方法与架构：** 它先用 AdaCare、ConCare、RETAIN 等 EHR 专家模型产生隐藏表征和 SHAP 解释，再由多个医生角色 agent 结合 RAG 医学知识进行多轮讨论，Meta agent 整理分歧与证据，最后将 LLM 生成报告编码后与 EHR 表征融合到监督预测模型。

**效果：** 在 MIMIC 任务中，完整 ColaCare 的 AUPRC 约 54.05，高于普通 ensemble 和去掉 MDT/专家模型/融合模块的消融版本，但提升幅度相对有限。

**创新与关注点：** 它的价值在于把“传统医学预测模型 + LLM 医生会诊 + 报告表征融合”连起来；需要注意最终预测仍依赖监督分类器，LLM 报告不是直接给出最终诊断。

### 16. ArgMed-Agents: Explainable Clinical Decision Reasoning with LLM Discussion via Argumentation Schemes

**解决的问题：** ArgMed-Agents 解决医学 LLM 多智能体讨论中理由不规范、冲突无法形式化处理、解释难以审计的问题。

**方法与架构：** 系统设置生成、验证和符号推理等 agent，将医学判断转成 argumentation schemes，再识别支持、反驳和冲突关系，并用偏好语义或论证规则筛选可接受结论。

**效果：** 在 MedQA、PubMedQA 等医学问答数据上，相比普通 LLM 讨论能提高回答和解释的一致性，尤其增强了冲突检测与可解释性。

**创新与关注点：** 这篇适合作为“可解释协作推理”的方法核心；但形式逻辑一致不代表医学前提真实，因此仍需接入高质量检索、指南和患者数据校验。

### 17. AgentDropout: Dynamic Agent Elimination for Token-Efficient and High-Performance LLM-Based Multi-Agent Collaboration

**解决的问题：** AgentDropout 解决多智能体系统虽然提升性能但 token 成本高、冗余 agent 参与过多的问题。

**方法与架构：** 它通过离线优化或搜索，在不同轮次动态删除不必要的 agent 或通信边，保留对任务贡献大的协作路径，从而让系统在更少 token 和更少交互下完成推理。

**效果：** 在多个多智能体推理任务中，AgentDropout 在减少 token 消耗的同时保持或提升性能，说明“少而准”的 agent 组合可能优于全员参与。

**创新与关注点：** 对你的课题很实用，因为真实诊疗系统必须控制成本、时延和无关信息干扰；但临床场景中删除 agent 要有安全规则，不能让优化器随意跳过关键检查或风险复核。

## 三、AD 疾病：医学诊断标准、临床流程与多模态诊断

### 18. 阿尔茨海默病源性轻度认知障碍诊疗中国专家共识

**解决的问题：** 这篇共识解决中国临床场景中 AD 源性 MCI 如何早期识别、诊断、鉴别诊断、干预和随访的问题。

**方法与架构：** 共识从流行病学、发病机制、临床表现、诊断与鉴别诊断、治疗、医护建议、风险因素与预防七个方面组织推荐，强调病史采集、体格检查、神经心理评估、实验室检查、血液/脑脊液生物标志物、PET/MRI 影像和至少 1 年随访的综合判断。

**效果：** 这不是算法效果论文，而是规范化诊疗框架；它给出了 MCI 筛查量表、AD 核心生物标志物、影像学检查和治疗建议的证据等级。

**创新与关注点：** 对你的系统最重要的是它提供了“中国临床语境下 AD 源性 MCI 的诊断流程和证据门槛”；需要把它作为医学规则库和报告依据，而不是当成模型性能证据。

### 19. Revised criteria for diagnosis and staging of Alzheimer's disease: Alzheimer's Association Workgroup

**解决的问题：** 这篇文章解决 AD 诊断从临床综合征诊断转向生物学定义后，如何用生物标志物定义和分期 AD 的问题。

**方法与架构：** 标准把 AD 定义为可由核心病理生物标志物检测到的生物过程，区分 Core 1 标志物（Aβ 与早期 tau 相关指标，可用于诊断）和 Core 2 标志物（如 tau PET 或部分 tau 指标，主要用于分期和严重度评估），同时把生物学分期和临床症状分期分开描述。

**效果：** 这不是实验模型，而是诊断与分期框架；它的效果体现在为临床试验、疾病修饰治疗和血液标志物时代提供统一语言。

**创新与关注点：** 它的关键变化是“异常 Core 1 生物标志物即可诊断 AD”，但也要特别注意文中不建议对普通无症状人群进行泛化筛查，且不同地区实施条件差异很大。

### 20. Alzheimer's Association clinical practice guideline for the Diagnostic Evaluation, Testing, Counseling, and Disclosure of Suspected AD/ADRD: Executive summary of recommendations for primary care

**解决的问题：** 这篇指南解决基层或一般临床环境中遇到认知、行为或功能下降患者时，应该如何系统开展 AD/ADRD 诊断评估的问题。

**方法与架构：** 指南提出多层级、问题导向的评估流程：先确定 cognitive functional status，再刻画 cognitive-behavioral syndrome，最后判断可能病因；一级评估包括病史和知情人信息、风险因素、体格和神经系统检查、简短认知工具、常规实验室和结构影像，并要求清晰、同理地披露诊断和制定后续计划。

**效果：** 这是临床实践指南，不报告模型准确率；其价值在于把诊断过程拆成可操作步骤，并明确哪些检查应该在几乎所有疑似患者中完成。

**创新与关注点：** 对你的系统非常关键，因为它能转化成 agent 工作流的基础骨架：病史 agent、量表 agent、影像 agent、实验室 agent、鉴别诊断 agent 和报告披露 agent 都可以围绕这个三步 formulation 组织。

### 21. Alzheimer's Association clinical practice guideline for the Diagnostic Evaluation, Testing, Counseling, and Disclosure of Suspected AD/ADRD: Executive summary of recommendations for specialty care

**解决的问题：** 这篇指南解决专科/亚专科环境中，常规评估后仍存在诊断不确定、病因复杂或表现 atypical 的患者该如何进一步检查的问题。

**方法与架构：** 它延续 primary care 的三步诊断 formulation，并重点补充转诊、完整神经心理评估、高阶实验室检查、FDG-PET、CSF、amyloid PET、遗传咨询与检测等二级到四级检查的适用场景；核心原则是根据综合征、先验概率、风险因素和不确定性选择检查，而不是 shotgun 式全量检查。

**效果：** 这同样是指南而非模型论文；其贡献在于界定何时需要专科检查、何时可以提高病因诊断置信度，以及哪些测试应谨慎使用。

**创新与关注点：** 它适合为你的系统设计“升级诊断路径”和“检查推荐 agent”：当初筛信息不足或出现早发、快速进展、非典型表现时，系统应触发专科级评估，而不是机械给出 AD 结论。

### 22. AI-based differential diagnosis of dementia etiologies on multimodal data

**解决的问题：** 这篇文章解决痴呆病因高度重叠、混合病因常见，临床医生难以仅凭单一模态区分多种痴呆病因的问题。

**方法与架构：** 作者构建多模态机器学习框架，融合人口学、神经心理、功能评估和多模态神经影像数据，并用标签掩蔽等策略处理不同队列中病因标签不完整的问题，输出 NC、MCI、痴呆状态以及 10 类痴呆病因的置信分数。

**效果：** 研究纳入 9 个数据集共 51,269 名参与者，模型在多病因鉴别中达到较高微平均 AUC，例如部分测试设置下 micro-AUC 约 0.94-0.96，并显示 AI 辅助临床判断优于单独临床判断。

**创新与关注点：** 它不是多智能体论文，但对你的疾病部分非常重要，因为它说明神经退行性疾病诊疗必须从“单病种 AD 分类”走向“多病因、多模态、混合病理鉴别”；注意其队列、人群和标签不均衡问题会影响少见病因泛化。
